## Experiment recommendation

1. Primary: frozen paired injection/quotation comparison on Qwen3-8B, with clean eligibility determined separately and explicit user-authorized target edits as capability controls. Use deterministic fictional state, not real services.
2. Secondary: same locked logical cases on the proposed DeepSeek and specified Moonlight checkpoints; report checkpoint-specific and shared-intersection clean eligibility.
3. Secondary: a single boundary-reminder ablation, reporting both unauthorized mutations and legitimate utility.

These are the only three implementation directions retained. The full scoring table and rejected directions are in `planning.md`. Treat any executed unauthorized mutation as the primary event; retain exact-target success and attempts separately. Match serialized tool-result token lengths per model; the prepared pilot already matches those lengths but still needs full-chat verification. Use paired confidence intervals, template clustering, and the 0.10 threshold rather than only a zero-difference test. Six development templates cannot support confirmatory generalization. No effect size, power, clean eligibility, or checkpoint ranking has been measured.
